# Getting Started

Setup lengkap LayangKit dengan penjelasan detail setiap langkah.

## Prerequisites

Sebelum mulai, pastikan Anda punya:

- **Node.js 18+** — [Download di nodejs.org](https://nodejs.org)
- **npm** — Sudah include dengan Node.js
- **Akun Cloudflare** — [Daftar gratis](https://dash.cloudflare.com/sign-up)
- **Text Editor** — VS Code direkomendasikan

## Step 1: Create Project

### Gunakan npm create (Recommended)

```bash
npm create layang@latest my-app
```

Wizard akan menanyakan:
```
? Project name: my-app
? Install dependencies: Yes
? Initialize git: Yes
```

Atau dengan opsi langsung:
```bash
npm create layang@latest my-app -- --install --git
```

### Atau Clone Manual

```bash
git clone https://github.com/maulanashalihin/svelte-kit-cloudflare-starter.git my-app
cd my-app
rm -rf .git  # Hapus git history
npm install
```

## Step 2: Understand the Structure

```
my-app/
├── src/
│   ├── lib/              # Shared code
│   │   ├── auth/         # Auth: password, session, google
│   │   ├── db/           # ⚠️ Hanya 2 files!
│   │   │   ├── index.ts  # All types + exports
│   │   │   └── schema.ts # Drizzle schema
│   │   ├── email/        # Resend email service
│   │   └── storage/      # R2 file storage
│   ├── routes/           # SvelteKit routes
│   │   ├── (dashboard)/  # Protected routes group
│   │   ├── auth/         # Auth endpoints
│   │   └── api/          # API endpoints
│   ├── app.css           # Tailwind + custom styles
│   └── hooks.server.ts   # Server hooks (auth injection)
├── migrations/           # Auto-generated by Drizzle
├── tests/                # Tests
├── wrangler.toml         # Cloudflare config
└── package.json
```

## Step 3: Setup Cloudflare

### Login

```bash
npx wrangler login
```

Browser akan terbuka untuk authorization. Klik **Allow**.

### Create Database

```bash
npx wrangler d1 create my-app-db
```

**Output penting:**
```toml
[[d1_databases]]
binding = "DB"
database_name = "my-app-db"
database_id = "xxxxx-xxxx-xxxx-xxxx-xxxx"
```

Copy ke `wrangler.toml`:

```toml
name = "my-app"
compatibility_date = "2024-09-23"

[[d1_databases]]
binding = "DB"
database_name = "my-app-db"
database_id = "xxxxx-xxxx-xxxx-xxxx-xxxx"
migrations_dir = "migrations"

[[r2_buckets]]
binding = "STORAGE"
bucket_name = "my-app-storage"
```

## Step 4: Setup Environment

Copy file example:
```bash
cp .env.example .env
```

Edit `.env` (untuk local development, sebagian besar opsional):
```env
# Required untuk deployment
CLOUDFLARE_ACCOUNT_ID=your_account_id
CLOUDFLARE_DATABASE_ID=your_database_id
CLOUDFLARE_API_TOKEN=your_api_token

# Optional: Google OAuth
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

# Optional: Email (Resend)
RESEND_API_TOKEN=
FROM_EMAIL=

# Optional: R2 (file uploads)
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
```

## Step 5: Database Migration

### Local Development

```bash
# Generate migration dari schema
npm run db:generate

# Apply ke local D1
npm run db:migrate:local

# Seed data (opsional)
npm run db:seed:local
```

### Verifikasi Database

```bash
# Open Drizzle Studio
npm run db:studio
```

Buka http://local.drizzle.studio untuk melihat database.

## Step 6: Run Development Server

```bash
npm run dev
```

Buka http://localhost:5173

## Step 8: Setup Optional Services

### Google OAuth

1. Buat project di [Google Cloud Console](https://console.cloud.google.com)
2. Enable Google+ API
3. Buat OAuth 2.0 credentials
4. Tambahkan ke `.env`:
   ```env
   GOOGLE_CLIENT_ID=xxx
   GOOGLE_CLIENT_SECRET=xxx
   ```

Detail: [Google OAuth Guide](./google-oauth)

### Email (Resend)

1. Daftar di [Resend](https://resend.com)
2. Verifikasi domain
3. Buat API key
4. Tambahkan ke `.env`:
   ```env
   RESEND_API_TOKEN=re_xxx
   FROM_EMAIL=noreply@yourdomain.com
   ```

Detail: [Resend Email Guide](./resend-email)

### File Upload (R2)

1. Buat bucket di Cloudflare R2
2. Buat API token dengan R2 permissions
3. Tambahkan ke `.env`:
   ```env
   R2_ACCOUNT_ID=xxx
   R2_ACCESS_KEY_ID=xxx
   R2_SECRET_ACCESS_KEY=xxx
   R2_BUCKET_NAME=my-app-storage
   ```

Detail: [R2 Setup Guide](./cloudflare-r2)

## Development Commands

```bash
# Development
npm run dev              # Start dev server
npm run check            # Type-check dengan svelte-check

# Building
npm run build            # Build untuk production
npm run preview          # Preview dengan Wrangler

# Testing
npm run test             # Unit tests (Vitest)
npm run test:watch       # Watch mode
npm run test:e2e         # E2E tests (Playwright)

# Database
npm run db:generate      # Generate migrations
npm run db:migrate:local # Apply ke local
npm run db:migrate       # Apply ke production
npm run db:studio        # Open Drizzle Studio

# Cloudflare
npm run deploy           # Deploy ke Cloudflare Pages
npm run logs             # View production logs
```
