## What is LayangKit?

LayangKit is a full-stack starter template with 5 AI Agents:

```
Your Idea
    ↓
@workflow/agents/product.md "I want to build..."
    ↓
Product Agent      → Requirements
Tech Lead Agent    → Technical Design  
Developer Agent    → Code
QA Agent           → Testing
DevOps Agent       → Deploy
    ↓
Live Application
```
